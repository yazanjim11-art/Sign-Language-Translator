# Real-Time Sign Language Translator 🖐️🤟

An AI-powered Computer Vision application that detects and translates hand gestures into text in real-time using OpenCV and MediaPipe.

---

## 🚀 Features
- **Real-Time Hand Tracking:** Detects hand landmarks using MediaPipe.
- **Gesture Recognition:** Translates gestures into words (e.g., Eat, Drink, Peace, Stop, Help, How are you).
- **Interactive UI:** Displays detected gesture overlays dynamically on the webcam feed.

---

## 🛠️ Requirements & Tech Stack
- **Python 3.8+**
- **OpenCV** (`opencv-python`)
- **MediaPipe** (`mediapipe`)
